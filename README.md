# Koordinata Street — sajt

Statični sajt, spreman za GitHub Pages. Sve slike i skripte su ugrađene u `index.html` — nema foldera koje treba posebno otpremati.

## Stranice
- `index.html` — sajt
- `blueprint.html` — dizajn sistem i arhitektura
- `pregled.html` — desktop + mobilni pregled jedan pored drugog

## Objavljivanje
1. Napravi novi repozitorijum na GitHubu i otpremi sav sadržaj ovog foldera u koren repozitorijuma.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
3. Sajt je za minut dostupan na `https://<korisnik>.github.io/<repo>/`.

Za sopstveni domen: dodaj fajl `CNAME` sa domenom (npr. `koordinata.rs`) i podesi DNS kod registra.
